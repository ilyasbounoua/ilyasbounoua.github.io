Le projet vise à développer un **système interactif innovant** destiné à améliorer le bien-être des aras en captivité au parc Planète Sauvage à Port-Saint-Père. Le système combine des **modules IoT basés sur Raspberry Pi** pour la diffusion sonore interactive et une **interface web full-stack** (Angular + Spring MVC) pour la supervision, la configuration et l'analyse des données comportementales.

### Objectifs principaux
1. Créer des **modules interactifs** déclenchant des sons en réponse aux interactions physiques des aras (bec, pattes).
2. Développer une **interface web de supervision** permettant la visualisation en temps réel des interactions et la configuration à distance.
3. Collecter et analyser des **données comportementales** pour évaluer l'utilisation du système par les aras.
4. Offrir aux soigneurs et chercheurs des **outils d'analyse statistique** pour optimiser le bien-être animal.
5. Garantir une solution **low-cost, évolutive et maintenable** avec un budget inférieur à 700€.

### Architecture et Technologies
- **Hardware** : Raspberry Pi 4B avec haut-parleurs étanches (IP65), microphones et capteurs d'interaction.
- **Backend** : Spring MVC (Java 17) avec architecture 3 couches (Controller, Service, DAO), API REST et Spring JDBC Template pour l'accès aux données PostgreSQL.
- **Frontend** : Angular 17+ avec TypeScript, Angular Material pour l'UI, navigation simple et composants réactifs.
- **Base de données** : PostgreSQL 15+ pour le stockage des interactions, configurations et modules.
- **Communication** : API REST pour la communication entre les modules IoT et le serveur central.

### Fonctionnalités principales
- **Authentification simple** : Page de login avec identifiants hardcodés et session HTTP classique.
- **Dashboard de supervision** : Visualisation du nombre total d'interactions, statut des modules, dernière interaction et diagrammes en bâtons des utilisations (jour/semaine/mois).
- **Liste des interactions** : Tableau paginé avec tri, filtres par date et export CSV des données.
- **Gestion des modules** : Vue détaillée par module (nom, localisation, statut, IP) avec configuration à distance (volume, mode manuel/automatique, activation/désactivation).
- **Gestion de bibliothèque sonore** : Interface pour gérer les sons diffusés par le système.
- **Export de données** : Téléchargement CSV des interactions pour analyse externe.

### Réalisation
- **Périmètre géographique** : Déploiement sur l'île des aras (~120m²) avec protection contre les intempéries et communication WiFi avec le serveur central.
- **Périmètre fonctionnel** : Focus sur la stimulation cognitive automatisée et la fourniture d'informations aux soigneurs, excluant les fonctionnalités avancées (IA, vidéo, application mobile).
- **Périmètre technique** : Solution open-source privilégiant la maintenabilité et l'évolutivité, avec architecture three-tier simplifiée.
- **Planning** : Développement sur 8 semaines avec répartition équilibrée entre backend (25h) et frontend (26h), incluant tests unitaires et déploiement.
- **Tests** : Tests unitaires minimaux avec JUnit 5 (backend) et Jasmine (frontend) pour garantir la qualité du code.

### Budget optimisé
Le projet respecte un **budget total de 417€** (sur 700€ alloués) :
- Matériel prototype (1 module) : 215€ (Raspberry Pi, haut-parleur, microphone, boîtier étanche)
- Infrastructure (hébergement cloud 6 mois + nom de domaine) : 72€
- Tests et validation : 80€
- Contingence : 50€
- Marge disponible : 283€ pour extensions futures

### Conclusion
Le projet démontre l'application de l'**IoT et des systèmes d'information** à la recherche sur le bien-être animal en milieu zoologique. La solution développée est **pragmatique, réaliste et évolutive**, avec une architecture permettant l'ajout progressif de fonctionnalités avancées (analyses statistiques poussées, IA comportementale, modules supplémentaires).

Les **principes directeurs** du projet (simplicité, pragmatisme, faisabilité, évolutivité) garantissent un système fonctionnel et maintenable à long terme. Ce travail illustre l'utilisation des **technologies modernes full-stack** (Angular, Spring, PostgreSQL) dans un contexte de recherche appliquée et d'innovation au service de la conservation animale.

Des **améliorations futures** incluront l'extension à plusieurs modules, l'intégration d'analyses comportementales avancées par IA, et le développement d'une application mobile pour les soigneurs.
