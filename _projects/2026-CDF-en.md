The **Coup de Feu** project addresses a major ergonomic paradox: the vital need for digital data in professional kitchens (order tickets, timers, allergy alerts) versus the prohibition of tactile interaction for hygiene reasons. This Android application synchronizes the kitchen brigade through a reactive interface that filters information by station and utilizes contactless interaction modalities.

## Key Objectives
1. Reconcile access to digital data with strict hygiene standards.
2. Synchronize various brigade members in real-time.
3. Provide role-specific views: "Micro" for workstations and "Macro" for the Head Chef.
4. Guarantee explicit control of actions via high-visibility visual feedback (120sp icons).
5. Ensure data persistence to restore the exact kitchen state after an app closure.

## Architecture and Technologies
* **Framework**: Jetpack Compose for a 100% declarative UI without XML.
* **Architecture**: MVVM pattern with a single ViewModel (`CoupDeFeuViewModel`) for global consistency.
* **Data Flow**: Utilization of `StateFlow` and `collectAsState()` for instantaneous UI updates.
* **Persistence**: `SavedStateHandle` with command serialization for robustness against Android lifecycles.
* **Design**: Strict adherence to a color-coded system (Orange for action, Blue for technical info, Red for urgency).

## Main Features
* **Station View (Sofia - Fish Station)**: Displays only tables requiring specific preparation. Includes a dynamic ticket grid generated by a deterministic algorithm.
* **Chef View (Marc - Coordination)**: Displays all 8 active tables with performance indicators (average service time).
* **Progress Gauges**: Dynamic visualization of progress by station (Cold, Fish, Meat) with color changes based on completion rate.
* **Contactless Interaction**: Simulation via specific buttons and confirmation through a "GESTURE DETECTED" overlay.
* **Instant Sync**: Validating a dish in a Station view immediately updates the gauges in the Chef view.

## Execution and Conclusion
This project was developed as part of the **INFO SI - DEVMO** specialization. The implementation validates the initial ergonomic choices, offering a fluid, high-contrast interface perfectly adapted to the visual constraints of a kitchen during the "rush" (coup de feu). The source code is modularly structured (Models, ViewModel, UI, Theme) to promote scalability.
