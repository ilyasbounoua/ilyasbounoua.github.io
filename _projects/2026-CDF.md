Le projet **Coup de Feu** résout un paradoxe ergonomique majeur : le besoin vital de données numériques en cuisine professionnelle (bons de commande, timers, allergies) face à l'interdiction de l'interaction tactile pour des raisons d'hygiène. Cette application Android synchronise la brigade via une interface réactive filtrant les informations par poste et utilisant des modalités d'interaction sans contact.

## Objectifs principaux
1. Concilier l'accès aux données numériques et le respect des normes d'hygiène strictes.
2. Synchroniser les différents membres de la brigade en temps réel.
3. Proposer des vues adaptées aux rôles : "Micro" pour les postes de travail et "Macro" pour le chef.
4. Garantir un contrôle explicite des actions via des retours visuels massifs (icônes de 120sp).
5. Assurer la persistance des données pour restaurer l'état exact de la cuisine après une fermeture.

## Architecture et Technologies
* **Framework** : Jetpack Compose pour une interface 100% déclarative sans XML.
* **Architecture** : Pattern MVVM avec un ViewModel unique (`CoupDeFeuViewModel`) pour la cohérence globale.
* **Flux de données** : Utilisation de `StateFlow` et `collectAsState()` pour des mises à jour d'UI instantanées.
* **Persistance** : `SavedState Handle` avec sérialisation des commandes pour la robustesse face aux cycles de vie Android.
* **Design** : Respect strict d'une charte colorimétrique (Orange pour l'action, Bleu pour le technique, Rouge pour l'urgence).

## Fonctionnalités principales
* **Vue Poste (Sofia - Station Poisson)** : Affiche uniquement les tables nécessitant une préparation spécifique. Comprend une grille de tickets dynamiques générés par un algorithme déterministe.
* **Vue Chef (Marc - Coordination)** : Affiche l'ensemble des 8 tables actives avec des indicateurs de performance (temps moyen de service).
* **Jauges de progression** : Visualisation dynamique de l'avancement par station (Froid, Poisson, Viande) avec changement de couleur selon le taux de complétion.
* **Interaction sans contact** : Simulation via des boutons spécifiques et confirmation par un overlay "GESTE DÉTECTÉ".
* **Synchronisation instantanée** : La validation d'un plat sur une vue Poste incrémente immédiatement les jauges de la vue Chef.

## Réalisation et Conclusion
Le projet a été développé dans le cadre de l'option **INFO SI - DEVMO**. L'implémentation valide les choix ergonomiques initiaux, offrant une interface fluide et contrastée parfaitement adaptée aux contraintes visuelles d'une cuisine en plein "coup de feu". Le code source est structuré de manière modulaire (Modèles, ViewModel, UI, Thème) pour favoriser l'évolutivité.
